认知与设计：理解UI设计准则（第2版）学习视频
制作与调整说明（v1）

交付范围
本视频根据对话中用户提供的全书精简文本改编，涵盖序言、引言、14章核心原理及复习。
采用约6200字的教学讲解、48页画面、中文合成旁白、嵌入字幕和章节标记。
这是一份核心内容的教学改编，不是逐字朗读，也未声称核验原版全书。
用户提供的后记、附录和参考文献只有标题，因此没有编造其具体内容。
全部界面图均为本次制作的示意图，不是书内原图或相关软件的真实截图。
建议先完整看一遍；熟悉后可用播放器的1.25倍速，按章节复习。
出现暂停题时，请真正暂停并用自己的话回答，再看解析。

工程目录
cognition_build/slides.json：可直接编辑的48页分镜，含标题、要点、检查句、讲解全文及图形类型。
cognition_build/content.py：最初的作者脚本，保留初始文本；后续以slides.json为准。
cognition_build/audio/000.mp3～047.mp3：每页独立旁白。
cognition_build/audio/*.json：语音返回的句子边界、时长、语音参数和缓存签名。
cognition_build/frames/：每页三张分步显示的1280×720 PNG画面。
cognition_build/subtitles/：每页SRT及ASS字幕，可编辑及追溯时间。
cognition_build/motion/：同步拖动与加载示意的独立动画。
cognition_build/scenes/：每页独立的中间MP4和缓存记录。
cognition_build/revisions/：已保留的源文件快照及重生成前的旧片段。
cognition_build/fonts/：字体及许可证，避免换机器时找不到中文字形。
cognition_build/speech.py：旁白生成脚本。
cognition_build/render.py：画面布局、颜色和图形绘制脚本。
cognition_build/assemble.py：分步显示、字幕、合成及章节索引脚本。
cognition_video/：成片所需的字幕、章节分镜与讲解稿等配套文件。

如何提出调整
按页码或时间描述，例如“第20页，把登录报错改成邮箱格式错误”；
或“13:59以后这一章讲慢一点”；或“第8页增加相关／不相关两种间距的对照”。
文件编号从000开始，对应视频显示的第01页。编号019对应第20页。

自己调整
先备份slides.json；编辑这个JSON，保留正确的JSON语法。
修改title、points、key只影响画面；修改narration会改变旁白与时长；visual选择图形类型。
改变图形具体布局，编辑render.py中对应的diagram分支。
改变语速，在speech.py修改RATE；当前是+8%，语音是zh-CN-XiaoxiaoNeural。
修改后按以下顺序运行：
  python speech.py
  python render.py
  python assemble.py
  python package.py
请在cognition_build目录运行。重新生成会更新各页时长、字幕与后续章节时间。
不要再次执行content.py来保存JSON，否则会用初始文案覆盖slides.json的编辑。
speech.py会复用文案与语音参数未变的音频；assemble.py会复用未变的片段。
变更前的旁白与片段自动备份到revisions，合成前源文件也会拍快照。
如果修改了字幕规则、编码或绘图脚本，缓存会失效并重生成相关片段。
若要直接改SRT／ASS而不改讲解文本，请先复制字幕再编辑；assemble.py会重新生成字幕。
最终MP4内字幕已烧入画面，关闭播放器字幕无法隐藏；独立SRT便于重新制作。

运行条件
Python 3.10以上；ffmpeg及ffprobe；Python包Pillow和edge-tts。
安装依赖：python -m pip install Pillow edge-tts
语音合成需要联网，绘图与视频合成可离线完成。
脚本为本次Linux制作环境编写；其他系统需确保ffmpeg可调用及字体可读取。
为了简单复用，建议工程路径不含空格或特殊符号。
播放最终MP4可用常见视频播放器；章节跳转的支持取决于播放器。

精度与修改记录
字幕以语音服务的句子时间为基础；极长句拆分时，句内子字幕按字数分配时间。
分步要点靠近句子边界出现，并不是逐字高亮。
保留原理的关键限制：4±1不是菜单项上限；识别优于回忆不是让所有输入都变为下拉框。
修正原文引导定律的简化：受约束路径移动同时受到路径长度及宽度影响。
视锥使用长、中、短波长及重叠响应的表述，避免把细胞当作独立单色传感器。
100毫秒、1秒等是情境相关的设计参考；部分其他时间数值未在主画面重复展开。
色觉缺陷比例因人群而异；六种基本色只是起点，不能代替对比和色觉检查。
屏幕边缘优势说明了鼠标条件，提醒不能直接照搬到触屏。
灰度预览是发现风险的方法，而不是完整可访问性合格认证。
双加工模型是一种解释框架，不是脑中两个独立器官。
