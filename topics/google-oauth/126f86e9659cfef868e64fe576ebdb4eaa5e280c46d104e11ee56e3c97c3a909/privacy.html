应用说明隐私政策使用条款

隐私政策 · Personal Contexts 存储

本页说明 llm-mcp 中 Personal Contexts 的 Google 存储接入如何处理授权和存储数据，适用范围仅为该存储接入。

处理的数据与用途

  • Google OAuth 凭证：用于执行用户同意范围内的 Drive 和 Photos API 调用。
  • 用户明确提供的文件、图片及必要名称、类型、描述：用于完成指定存储任务。
  • 应用可访问的 Drive 文件元数据：用于生成数量和大小等存储盘点结果，不代表全库盘点。

保存与共享

OAuth 凭证保存在所有者管理的 Bitwarden Secrets Manager 中；本机机器身份由操作系统凭证存储保护。调用时凭证在执行器内处理，不向聊天、模型、浏览器页面或普通执行日志输出。

文件或图片按用户指令提交到 Google。存储执行日志保留操作状态及必要的非秘密结果摘要，不记录 OAuth 令牌、授权 code、文件正文或图片字节。本地存储执行器不出售 Google 用户数据，不将其用于广告或本地模型训练。

如果通过 Agent 发起存储任务，Google API 派生的非秘密结果也会返回给请求方 Agent，并可能进入所用模型服务的上下文：包括盘点计数、逻辑大小，以及上传结果中的文件 ID、类型、大小和摘要。这些结果用于完成、解释和展示本次请求；用户对话及这些结果均受所选 Agent 和模型服务的数据处理规则约束。本地执行器不会发送 OAuth 凭证或文件正文，但本页不能保证第三方模型服务的保留或训练政策；使用前需核对对应服务规则。

保留与删除

重新授权的私有维护 journal 保留批准引用、时间、状态和令牌的单向摘要，用于防止重复更新及核对未知结果；不保存令牌明文。凭证、维护 journal 和本机审计不设自动删除期限，由所有者管理。停止集成后，所有者可请求删除专用凭证、维护记录和审计；删除未完成记录会影响对账和防重复能力，需要先处理未完成动作。凭证删除不代替 Google 账号中的权限撤销。

存入 Google Drive 或 Google Photos 的数据依照用户账号中的管理方式保留，用户可在 Google 产品内自行删除。用户可在 Google 账号第三方连接管理中撤销访问；撤销后新的受保护调用无法继续使用该授权，不自动删除已存储数据。

Google API 数据政策

本接入对 Google API 数据的使用和转移必须遵守 Google API Services User Data Policy，包括 Limited Use 要求；仅使用必要的数据完成用户明确要求的存储与盘点功能。本接入不得将 Google 用户数据（包括派生结果）用于创建、训练或改进超出该特定用户个性化模型的任何机器学习或人工智能模型。维护本接入的开发者负责确保所用 Agent、模型服务及其他受托处理方遵守 Limited Use；无法确认满足要求的处理方不得接收这些数据。
